AgentOne: Real Estate Platform (Case Study)


Live platform: https://agentone.in/
Role: Junior Full Stack Developer at SCWEBS Info Solutions (Sep 2025 – Present)
Scale: 50+ active property agents across 2 cities

Note: The source code is proprietary to SCWEBS Info Solutions Pvt. Ltd. This case study documents architecture, features implemented, and measurable engineering outcomes.

Core Contributions
Component Architecture: Built 15+ reusable React and Tailwind CSS components (property cards, multi-facet filter bars, paginated listings), standardizing the design system.

API Development: Implemented 12+ Express REST endpoints managing property listings, agent lead routing, and role-based access control.

Database Indexing & Performance: Profiled slow queries and implemented compound indexes in MongoDB, reducing search latency by 73% (from ~3.2s to 850ms).

Real-Time Communication: Integrated Socket.io with Redis pub/sub adapters to support live buyer-agent chat without polling overhead.

Cloud Infrastructure: Deployed containerized services on AWS EC2 behind an Nginx reverse proxy with SSL termination and gzip compression.

Tech Stack
React, Next.js, TypeScript, Node.js, Express, MongoDB, Redis, Socket.io, AWS EC2, Nginx, GitHub Actions
